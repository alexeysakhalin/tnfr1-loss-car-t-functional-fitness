# Numerical reference results

This directory contains compact, non-identifying numerical contracts used to
verify manuscript-level results:

- nivolumab-only CheckMate survival and signature associations;
- Figure 5G combined B2M/ICAM1 model results;
- transferred-signature gene coverage;
- DepMap Supplementary Figure S1B counts and percentages;
- aggregate source-quality-control values.

Patient-level expression and clinical tables are not stored here. The scripts
that regenerate or verify each file are listed in
[`docs/FIGURE_MAP.md`](../docs/FIGURE_MAP.md).
